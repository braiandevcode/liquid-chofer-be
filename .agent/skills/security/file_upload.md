## FILE_UPLOAD

### RULES 
- Verify, analyze, and fix with RIGOR:
    - every file upload point (images, documents, avatars, attachments, imports) where XSS, code execution, or another injection attack may occur:
    - extension: allow only an allowlist of safe extensions (e.g. `.jpg`, `.png`, `.webp`) and reject double extensions (`shell.php.jpg`), case variations, null byte, and executable or active extensions (`.php`, `.jsp`, `.html`, `.svg`, `.js`)
    - real file type: validate magic bytes and MIME type on the server, without trusting the `Content-Type` or the extension sent by the client
    - internal content and metadata (EXIF, comments, XMP): look for XSS or injection payloads, and detect polyglot files (a valid image with embedded code)
    - file name: treat it as untrusted input (path traversal, special characters, injection in logs or the DB)
    - size and dimensions: limit weight and resolution to prevent DoS (decompression bombs, pixel flood)
    - formats that contain XML or scripts (SVG, DOCX, XLSX, PDF): block them or process them safely (XSS, XXE, macros, embedded JavaScript)
- Reprocess images on the server (decode and re-encode with an up-to-date library) to remove metadata and any embedded content, instead of trying to "sanitize" the original file.
- Store securely: rename with random names (UUID) generated by the server, store outside the webroot or in object storage, with no execute permissions on the uploads directory, and serve from a separate domain or subdomain.
- Serve with secure headers: correct `Content-Type`, `X-Content-Type-Options: nosniff`, `Content-Disposition: attachment` when files should not be displayed in the browser, and strict CSP.
- Reinforce with defense in depth: require authentication and authorization on upload, rate limits and per-user quotas, antimalware scanning, up-to-date image processing libraries (e.g. ImageMagick, libvips), and logging of rejected attempts.
- If a vulnerability is detected: fix it, test with payloads (double extension, spoofed `Content-Type`, manipulated magic bytes, polyglot, SVG with script, EXIF with payload, and Zip Slip) to confirm it has been mitigated, and report to me the finding, its location, the cause, and the fix applied.
